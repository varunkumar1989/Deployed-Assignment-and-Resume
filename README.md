# Resume

Varun Kumar · product and UX case studies.

## Deploy to Netlify

Drag the [`resume-site`](./resume-site) folder onto Netlify (Deploys, then "drag and drop your site output folder"), or unzip [`downloads/varun-resume-site.zip`](./downloads/varun-resume-site.zip) and drag the unzipped folder. The zip re-creates the whole site.

| Path | What |
|---|---|
| `index.html` | Resume page with case-study cards and all other projects |
| `case-studies/oyo/` | OYO Two Journeys prototype, 10-page deck, 23-page report |
| `case-studies/zomato/` | Zomato Customer & Partner prototype, 10-slide deck, 19-page report |
| `case-studies/noon/` | Noon UAE heuristic evaluation (page and 16-page PDF) |
| `case-studies/klook/` | Klook UX evaluation (page and 8-slide PDF) |

## Edit the resume

Open `resume-site/index.html` and find the `RESUME` block near the bottom. Fill in `summary`, `experience` and `education`. Empty sections stay hidden, so nothing shows until you add it. Then commit, or re-drag the folder onto Netlify.

Dragging a folder replaces the whole Netlify site, so deploy the complete `resume-site` folder every time.
